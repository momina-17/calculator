#  Modern Calculator

A modern and interactive calculator built using **HTML, CSS, and JavaScript**. It features a sleek dark interface, circular buttons, green operator accents, and an orange equals button for a clean, modern look.

##  Features

-  Basic arithmetic operations: Addition, Subtraction, Multiplication, and Division
-  Percentage calculation
-  Number buttons, including double-zero (`00`)
-  **AC** button to clear all input
-  **DEL** button to delete the last character
-  Decimal number support
-  Modern dark UI with 3D-style buttons and shadows
-  Responsive design (if implemented in the project)

##  Technologies Used

- **HTML5** – Structure of the calculator
- **CSS3** – Styling, layout, and visual effects
- **JavaScript** – Calculator functionality and user interactions

##  How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/momina-17/modern-calculator.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.
4. Start performing calculations!
